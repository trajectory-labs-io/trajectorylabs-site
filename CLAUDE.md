# trajectorylabs-site
## Work board (keep it in sync)

Every session keeps its GitHub issue in step with the work on the trajectory-labs-io board (org Projects #1). Labels
drive the board (ops README, "Board labels"); never hand-edit board fields.
- **Start:** find the matching open issue, or open one, and set `status:in-progress`. Code work for this repo's app goes here; non-code work (accounts, vendors, DNS, listings, marketing, admin) goes in trajectory-labs-io/ops.
- **Labels:** one each of `owner:`, `project:` (`project:trajectory-labs`), `category:` and `priority:`. Put `Due: YYYY-MM-DD` in the body
  when there is a date. Add `human` to anything a person must do (sign-ins, payments, Apple or vendor forms, approvals).
- **Blocked:** set `status:blocked` and comment what it waits on and who.
- **Finish:** comment the evidence (commit, PR, link, screenshot), then close the issue (closing sets Done). If only
  part is done, comment what is left and keep it open.
- GhostWall work never goes on this board.
- If the session can't reach GitHub, list the issue changes in the handoff (STATE.md) for the next session.
